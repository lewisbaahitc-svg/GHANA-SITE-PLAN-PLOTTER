# Ghana Site Plan Plotter

**Developed by Lewis Baah**  
**© 2026 Lewis Baah. All Rights Reserved.**

Ghana Site Plan Plotter is a coordinate-based surveying and site-plan support tool developed by Lewis Baah.

## Features
- 3–100 coordinate points
- Ghana coordinate-system options
- Area and perimeter calculations
- Bearings and distances
- CSV/Excel export
- DXF export
- KML export for Google Earth
- Online satellite/map checking when internet is available
- Offline plotting and calculations
